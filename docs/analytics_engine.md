# NovaVCS Repository Analytics Engine

The Analytics Engine parses the `.nova` internal structures and the working tree to generate actionable insights regarding repository health, storage usage, and team activity.

## Web Dashboard Integration (API Ready)

To support integration with future enterprise dashboard applications (such as a Node.js/Express API layer storing historical data in PostgreSQL), the `nova analyze` command directly outputs a structured JSON payload. 

By piping this output, backend services can ingest repository metrics without needing to compile C++ bindings.

**Example Express.js Ingestion:**
```javascript
const { exec } = require('child_process');

app.get('/api/v1/repo/stats', (req, res) => {
    exec('nova analyze', (error, stdout, stderr) => {
        if (error) return res.status(500).json({ error: stderr });
        
        // Parse the raw JSON string generated by the C++ engine
        const repoStats = JSON.parse(stdout);
        
        // Save to PostgreSQL or return to the React frontend
        res.json(repoStats);
    });
});
